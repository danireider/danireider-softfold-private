# Softfold

**Close the lid, and your desktop folds away softly.**

This repository is a private, telemetry-free copy of the original project, with outbound data collection removed.

</div>

---

Softfold follows your MacBook's hinge. As you lower the screen, your live desktop tilts back with it, blurs from the top down and fades into the dark edges. Lift it again and everything comes back.

## Build from source

Install Xcode, then:

```sh
git clone https://github.com/danireider/danireider-softfold-private.git
cd danireider-softfold-private
make build
open build/Softfold.app
```
